---
title: Teams
description: Share encrypted secrets with teammates through git, and revoke access when someone leaves.
---

By default, a project is in **individual mode**: your encrypted secrets stay on your machine. **Team mode** moves them into the repository, encrypted for every teammate's public key, so the team shares one set of credentials without passing around a plaintext `.env`.

<Steps>
<Step>

### Turn on team mode (once per project)

```bash
rabbitlock team enable
```

This moves your encrypted secrets into `secrets.sops.json` in the repo and lists you as the first **recipient** in `rabbitlock.agent.yaml`. Commit both files.

</Step>
<Step>

### Each teammate sends you their public key

In the repo, they run:

```bash
rabbitlock init     # creates their identity; keeps the existing policy
rabbitlock key      # prints their public key, which is safe to share
```

</Step>
<Step>

### Add them

```bash
rabbitlock team add <their-key> --name ana
```

This re-encrypts the file so `ana` can decrypt it. Commit `rabbitlock.agent.yaml` and `secrets.sops.json`; once they pull, they can run `rabbitlock run -- claude` with the same secrets.

</Step>
</Steps>

`rabbitlock team ls` shows who can decrypt.

## Removing someone

```bash
rabbitlock team remove ana
```

New versions of the file are no longer encrypted for them. They can still decrypt **older versions** from git history, so RabbitLock lists the secrets they had access to. **Rotate those tokens** at each provider, then store the new values with `rabbitlock set`.

## Policy changes are code changes

`rabbitlock.agent.yaml` decides where each secret may go, for everyone on the team. Review changes to it like code, especially new hosts. During a session the agent can't modify it: the [sandbox](/concepts/sandbox) makes it read-only.

## What's coming for teams

Today, team mode shares secrets through git. The hosted team workspace (in early access) adds shared policy without commits, central receipts, approvals on Slack or your phone, and offboarding that tells you which tokens to rotate. See [plans](https://rabbitlock.com/plans).
